# Basic-Cards-Game
To play this game:
1. Copy or download this repository.
2. Open your terminal or command prompt in the project directory.
3. Run the game using the following command:

```bash
python Cards_Game.py

You start with four cards in your hand, and so does the computer. They each have their own cost, health, and attack stat. For the first turn, you get 1 Power (used to play a card depending on the cost it has) and you get 2 for the second turn etc. 
You and the computer have 20 Health. Use your cards to deal damage to the computer. You can also use them to block damage from the computer's cards. To use a card, type the number of the order your card is in (for example you want to play the 3rd card in your hand, type 3). To skip lanes, type 0.
That's pretty much it. Enjoy!
